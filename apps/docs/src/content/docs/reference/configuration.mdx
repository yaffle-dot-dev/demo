Configuration lives in `yaffle.toml` at your repository root.

## Minimal example

```toml
version = 1

[[environments]]
name = "production"

[[triggers.github.push]]
ref_patterns = ["refs/heads/main"]
environment = "production"

[[triggers.github.pull_request]]
branch_patterns = ["*"]

[[workspaces]]
path = "infra"
environments = ["*"]
```

## Full example

```toml
version = 1

# Named environments
[[environments]]
name = "production"

[[environments]]
name = "staging"

# Push to main → production
[[triggers.github.push]]
ref_patterns = ["refs/heads/main"]
environment = "production"

# Push to staging → staging
[[triggers.github.push]]
ref_patterns = ["refs/heads/staging"]
environment = "staging"

# All PRs create transient previews
[[triggers.github.pull_request]]
branch_patterns = ["*"]

# Shared infra runs in both environments
[[workspaces]]
path = "infra/shared"
environments = ["production", "staging"]
variables.cloudflare_zone_id = "abc123"

# Production-only workspace
[[workspaces]]
path = "infra/production"
environments = ["production"]

# App infra runs in all environments (including PR previews)
[[workspaces]]
path = "apps/api/infra"
environments = ["*"]
variables.domain = "{{ environment }}.yaffle.dev"

# Publish a curated platform API to selected workspaces across repos or orgs
[[workspaces]]
path = "platform/eks"
environments = ["production", "staging"]

outputs.cluster_endpoint = { visibility = "public", consumers = ["acme:yaffle-dot-dev/yaffle:apps/*"] }
outputs.cluster_ca = { visibility = "public", consumers = ["acme:yaffle-dot-dev/yaffle:apps/*"] }

# Require approval for production changes
[[approvals]]
workspaces = ["infra/production", "infra/shared"]
environments = ["production"]
approvers = [
  "github:user:alice",
  "github:team:acme/platform",
]
```

## Reference

### `version`

Always `1`.

```toml
version = 1
```

### `[[environments]]`

Named environments your workspaces can target.

```toml
[[environments]]
name = "production"

[[environments]]
name = "staging"
```

PR previews are *transient* environments—they don't need to be declared.

### `[[triggers.github.push]]`

Run workspaces when a ref (branch or tag) is pushed.

| Field | Description |
|-------|-------------|
| `ref_patterns` | Include globs for full refs (must start with `refs/heads/` or `refs/tags/`) |
| `exclude_ref_patterns` | Optional exclude globs applied after includes |
| `environment` | Which environment to target |

```toml
# Trigger on branch push
[[triggers.github.push]]
ref_patterns = ["refs/heads/main"]
environment = "production"

[[triggers.github.push]]
ref_patterns = ["refs/heads/staging/*"]
exclude_ref_patterns = ["refs/heads/staging/archive/**"]
environment = "staging"

# Trigger on tag push
[[triggers.github.push]]
ref_patterns = ["refs/tags/v*"]
environment = "release"
```

`ref_patterns` uses OR semantics: a push matches if it matches any include pattern and no exclude pattern. Legacy `ref = "refs/heads/main"` remains supported as a shorthand for a single include pattern.

Ref globs use `*` for a single path segment and `**` to match across `/`.

### `[[triggers.github.pull_request]]`

Create transient previews for PRs.

| Field | Description |
|-------|-------------|
| `branch_patterns` | Include globs for the head branch (`["*"]` = all PRs) |
| `exclude_branch_patterns` | Optional exclude globs applied after includes |

```toml
[[triggers.github.pull_request]]
branch_patterns = ["*"]
exclude_branch_patterns = ["dependabot/**"]
```

`branch_patterns` uses OR semantics: a PR matches if it matches any include pattern and no exclude pattern. Legacy `branch_pattern = "*"` remains supported as a shorthand for a single include pattern.

### `[[workspaces]]`

OpenTofu directories Yaffle manages. (Terraform directories work too—OpenTofu is fully compatible.)

| Field | Description |
|-------|-------------|
| `path` | Path to OpenTofu/Terraform directory |
| `environments` | Which environments run this workspace |
| `variables` | Variables to inject |
| `outputs` | Optional per-output visibility rules for cross-repo module consumers |

```toml
[[workspaces]]
path = "infra/api"
environments = ["*"]
variables.environment = "{{ environment }}"
variables.region = "us-east-1"
```

#### Environments

- `["production"]` — Only runs in production
- `["production", "staging"]` — Runs in both
- `["*"]` — Runs in all environments, including PR previews

#### Variables

Variables are injected as `-var` flags. Use `{{ environment }}` to template the current environment name.

```toml
variables.environment = "{{ environment }}"
variables.domain = "{{ environment }}.example.com"
```

#### Outputs

Outputs are internal by default for same-repo consumers. Use `outputs.<name>` to make specific outputs public for allowlisted external consumers.

```toml
[[workspaces]]
path = "platform/database"
environments = ["production", "staging"]

outputs.connection_string = { visibility = "public", consumers = ["acme:yaffle-dot-dev/yaffle:apps/*"] }
outputs.secret_arn = { visibility = "public", consumers = ["acme:yaffle-dot-dev/yaffle:apps/*"] }
```

`outputs.<name>` fields:

| Field | Description |
|-------|-------------|
| `visibility` | `internal` or `public` |
| `consumers` | Required for `public`; allowlist of `<org-slug>:<repo-slug>:<workspace-pattern>` |

Rules:

- `internal` outputs are only available to downstream workspaces in the same repo
- `public` outputs are available only to explicitly allowlisted workspaces in other repos or orgs
- same-repo consumers can still read the full module surface
- consumer selectors match Yaffle org slug, repo slug, and workspace path

<Aside type="note">
Public exports are for stable platform APIs. If a Terraform output is marked `sensitive = true`, don't export it publicly. Store the value in Secrets Manager or SSM, export the ARN or name instead, and grant consumers IAM access to read it directly.
</Aside>

### `[[approvals]]`

Require approval before applying.

| Field | Description |
|-------|-------------|
| `workspaces` | Paths or globs |
| `environments` | Which environments |
| `approvers` | Who can approve |

```toml
[[approvals]]
workspaces = ["infra/*"]
environments = ["production"]
approvers = [
  "github:user:alice",
  "github:user:bob",
  "github:team:acme/platform-engineering",
]
```

#### Approver syntax

```
<provider>:<type>:<identifier>
```

| Example | Meaning |
|---------|---------|
| `github:user:alice` | GitHub user alice |
| `github:team:acme/platform` | GitHub team @acme/platform |

#### Matching

Multiple approval blocks can match. Approvers are combined. Any single approver can approve.

## Variable templating

Use `{{ }}` in variable values. Yaffle uses [MiniJinja](https://github.com/mitsuhiko/minijinja) syntax.

### Available variables

| Template | Description | Example value |
|----------|-------------|---------------|
| `{{ environment }}` | Environment name | `production`, `pr-42` |
| `{{ environment_kind }}` | `named` or `transient` | `transient` |
| `{{ org }}` | GitHub organization/owner | `acme` |
| `{{ repo }}` | Repository name | `infra` |
| `{{ workspace_path }}` | Workspace path | `infra/network` |
| `{{ branch }}` | Git branch name | `main`, `feature/login` |
| `{{ commit_sha }}` | Full commit SHA | `a1b2c3d4...` |
| `{{ pr_number }}` | PR number (null for named envs) | `42` |

### Examples

```toml
[[workspaces]]
path = "infra"
environments = ["*"]
variables.env = "{{ environment }}"
variables.bucket = "{{ org }}-{{ repo }}-{{ environment }}"
variables.commit = "{{ commit_sha }}"
```

### Filters

MiniJinja filters are supported:

```toml
variables.branch_slug = "{{ branch | replace('/', '-') }}"
variables.env_upper = "{{ environment | upper }}"
variables.fallback = "{{ pr_number | default('main') }}"
```

### Conditionals

```toml
variables.domain = "{% if environment_kind == 'transient' %}preview-{{ pr_number }}{% else %}{{ environment }}{% endif %}.example.com"
```

## Glob patterns

Globs work in `ref`, `branch_patterns`, `exclude_branch_patterns`, `workspaces`, and `environments`:

| Pattern | Matches |
|---------|---------|
| `*` | Anything within a single path segment |
| `**` | Anything, including `/` |
| `refs/heads/feature/*` | `refs/heads/feature/login`, but not `refs/heads/feature/a/b` |
| `dependabot/**` | `dependabot/npm_and_yarn/foo` |
| `refs/tags/v*` | `refs/tags/v1`, `refs/tags/v1.0.0` |
| `infra/*` | `infra/foo`, `infra/foo/bar` (workspace patterns match across `/`) |
