## What's a preview?

An isolated OpenTofu workspace that exists while a PR is open.

```
PR opened   → Preview created, tofu apply
PR updated  → Preview updated, tofu apply
PR merged   → Preview destroyed; configured production owner handles deploy
PR closed   → Preview destroyed
```

## Isolation

Each preview gets:

- **Unique state** — `previews/pr-42/terraform.tfstate`
- **Namespaced resources** — via `{{ environment }}` variable

```hcl
resource "aws_s3_bucket" "data" {
  bucket = "myapp-${var.environment}"
}
```

PR #42 creates `myapp-pr-42`. No collision with PR #99 or production.

## Lifecycle

| PR Event | Yaffle Action                                                             |
| -------- | ------------------------------------------------------------------------- |
| Opened   | `plan` → `apply` to preview                                               |
| Pushed   | `plan` → `apply` to preview                                               |
| Merged   | `destroy` preview; Yaffle or customer CI may separately deploy production |
| Closed   | `destroy` preview                                                         |

## Outputs

After apply, non-sensitive outputs are available to authorized viewers. Sensitive values are
structurally redacted, and automation receives only outputs explicitly selected in `yaffle.toml`.

**In the GitHub check:**

```
Outputs:
  api_url = "https://pr-42.api.example.com"
```

**Via the environment API:**

```bash
curl --header "Authorization: Bearer $YAFFLE_API_TOKEN" \
  "https://api.yaffle.dev/api/orgs/acme/repos/app/environment/pr-42"
```

The response is the current environment representation. Select the required workspace's
`outputs`; do not treat a preview route or its raw output map as the immutable shared-output
contract.

**In GitHub Actions:**

```yaml
- uses: yaffle-dot-dev/outputs-action@v1
  with:
    environment: pr-${{ github.event.pull_request.number }}
    workspace: infra
```

## Preview status

| Status       | Meaning                     |
| ------------ | --------------------------- |
| `pending`    | Waiting for runner          |
| `planning`   | Running `terraform plan`    |
| `applying`   | Running `terraform apply`   |
| `ready`      | Infrastructure is up        |
| `failed`     | Run failed                  |
| `destroying` | Running `terraform destroy` |
| `destroyed`  | Cleaned up                  |
