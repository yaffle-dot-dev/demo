Configure Yaffle to run your existing OpenTofu in pull-request environments.

Yaffle automatically isolates state and runner execution today. During beta, resources
with globally unique provider names usually need to include the environment name so
concurrent previews do not collide. Provider-aware isolation without configuration
changes remains a product goal, not a constraint of the environment model.

<Steps>
1. ### Install the GitHub App

[Install Yaffle](https://yaffle.dev/app) on your repository.

2. ### Connect your AWS account

   Yaffle needs credentials to run OpenTofu. Add them in the dashboard or via connection config.

3. ### Add `yaffle.toml`

   ```toml
   # yaffle.toml
   version = 1

   [[environments]]
   name = "production"

   [[environments]]
   name = "staging"

   [cloud]

   [[cloud.triggers.github.push]]
   ref_patterns = ["refs/heads/main"]
   environment = "production"

   [[cloud.triggers.github.push]]
   ref_patterns = ["refs/heads/staging"]
   environment = "staging"

   [[cloud.triggers.github.pull_request]]
   branch_patterns = ["*"]

   [[workspaces]]
   path = "infra"
   environments = ["*"]
   variables.environment = "{{ environment }}"
   ```

4. ### Choose who owns production

   Keep the push trigger above if Yaffle should manage the named `production` environment.
   Otherwise remove both push triggers and named environments; your existing CI can remain the
   production owner.

5. ### Open a PR

   Yaffle will:
   - Plan and apply to an isolated preview
   - Post outputs (URLs, connection strings) to the PR
   - Update on every push
   - Destroy when the PR closes

</Steps>

## Example Terraform

```hcl
# infra/main.tf
variable "environment" {
  type = string
}

resource "aws_s3_bucket" "data" {
  bucket = "myapp-${var.environment}"
}

output "bucket_name" {
  value = aws_s3_bucket.data.bucket
}
```

For production: `myapp-production`  
For a PR: `myapp-pr-42`

## What you'll see

On push to main:

```
Yaffle / infra (production)
Plan: +1 ~0 -0
Applied successfully.
```

On PR:

```
Yaffle / infra (environment: pr-42)
Plan: +1 ~0 -0

+ aws_s3_bucket.data
    bucket = "myapp-pr-42"

Applied. Outputs:
  bucket_name = "myapp-pr-42"
```

<Aside type="tip">
  Use the [outputs action](/docs/guides/github/) to fetch Terraform outputs in your CI pipeline and
  deploy your application to the preview infrastructure.
</Aside>
